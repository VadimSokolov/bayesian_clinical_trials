This appendix describes the software that accompanies the book. It covers installation (R and the bayestrials package, with its tests), how the package is organized (functions in snake case whose prefix names the part of the book, with one argument convention throughout), a worked example, reproducibility (seeds visible beside every simulation, Monte Carlo error reported with results), the companion lab (an interactive tutorial with modules matching the chapters and a Bayesian trial simulator), and established trial design software in wide use: rpact, gsDesign, RBesT, SampleSizeProportions and SampleSizeMeans, BOIN, trialr, adaptr, bcrm, Stan and brms, FACTS and East Horizon, with a brief statement of the purpose of each. The descriptions cover only the purpose of each tool, so the reader should consult the tool's documentation for current features and versions. It contains no results.

## From the literature

Established software for trial design: rpact and gsDesign for group sequential designs, RBesT for meta analytic predictive priors (Weber and colleagues 2021), SampleSizeProportions and SampleSizeMeans for Bayesian sample size (Joseph and colleagues), BOIN for dose finding (Yuan and colleagues), trialr, adaptr, bcrm, Stan and brms for Bayesian models, and the commercial packages FACTS and East Horizon.
